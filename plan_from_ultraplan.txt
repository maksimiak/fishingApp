# Phase 3 — Make every water body click open the curated DetailScreen

## Context

The existing UX is the design — we're not redesigning it. Today only the 10 curated water bodies route to `DetailScreen` on tap; everything else shows a placeholder card on the map. The goal is to make **any** tappable water body land on the same `DetailScreen` flow, with the rules surface there showing the full zvejogidas.lt §11 ruleset, the "can I fish today" verdict, and (for the curated 10) the body-specific overrides on top. The map itself stays exactly as-is — same tile style, same green/amber/red curated overlays.

User's reference layout for the rules surface lives at `C:\Users\ITwork\dev\fishingapp\map_ex.png` and `C:\Users\ITwork\dev\fishingapp\map_ex2.png`. The implementer needs to open those locally before finalising the rules-card layout — they govern the visual.

Out of scope: amateur/limited section split (drop it everywhere), map tile tinting, new tabs, schema rework.

## Engine: one helper

`mobile/src/data/rules/index.ts`:

```ts
export function getDailyVerdict(
  waterBodyId: string | null,   // null → national defaults only
  date: Date,
): {
  open: EffectiveSpeciesRule[];
  closed: EffectiveSpeciesRule[];
  blanketReason: ClosureWindow | null;
};
```

Iterate `NATIONAL_SPECIES_RULES`, call existing `getEffectiveSpeciesRule(s.speciesId, waterBodyId ?? '__national__', date)` per species, partition by `status`. Read `getWaterBodyRules(waterBodyId)?.blanketClosures` separately and match `date` for `blanketReason`. `getEffectiveSpeciesRule` already falls back cleanly when the id is unknown — no changes needed there.

## Routing: any tap lands on DetailScreen

Today's flow: curated tap → `router.push('/waterbody/' + id)` → `app/waterbody/[id].tsx` looks the id up in `WATER_BODIES` → renders `DetailScreen`. Non-curated tap → in-map card with a placeholder.

Change:
1. **`mobile/src/data/waterbodies.ts`** (or wherever `WATER_BODIES` lives): add a `resolveWaterBody(id, tileProps?)` helper. Returns the curated record if `id` matches; otherwise returns a synthesised stub:
   ```ts
   {
     id,                         // stable id from MapTiler tile (osm_id or name slug)
     name: tileProps.name_lt ?? tileProps.name,
     nameEn: tileProps.name_en ?? tileProps.name,
     type: tileProps.class === 'river' ? 'river' : 'lake',
     geometry: tileProps.geometry,
     species: [],                // empty → SpeciesTab falls back to national list
     curated: false,             // new flag
   }
   ```
2. **`mobile/src/screens/MapScreen.tsx`**: replace the non-curated `selectedCard` rendering with the same `router.push('/waterbody/' + id)` call the curated branch uses. Pass the tile's `name`, `name_en`, `class`, and `osm_id` as nav params so the detail route can synthesise without re-querying the tile.
3. **`app/waterbody/[id].tsx`**: read params, call `resolveWaterBody(id, params)`, render `DetailScreen` with the resolved body.

Stable id strategy for non-curated bodies: prefer `osm:` + `osm_id` from the MapTiler tile; if absent, fall back to a slug of `name + bbox-center`. Document this in `resolveWaterBody`.

## DetailScreen: accommodate ad-hoc bodies + add the rules surface

`mobile/src/screens/DetailScreen.tsx`:

- **Header**: existing layout; add `<TodaysVerdictBanner waterBodyId={wb.id} date={date} />` directly under the title for both curated and ad-hoc bodies.
- **RulesTab**: rebuild as
  1. Per-body overrides block — render `getWaterBodyRules(wb.id)` only if it returns non-null. List `blanketClosures` (reason + dates + source) and any `speciesOverrides` deltas vs national. Skip the block silently for ad-hoc bodies.
  2. `<NationalRulesCard date={date} waterBodyId={wb.id} lang={lang} />`.
- **SpeciesTab**: when `wb.species.length === 0` (ad-hoc), render the full national species list from `NATIONAL_SPECIES_RULES` instead of the curated subset. Keep the existing per-species row layout.
- **InfoTab**: when `wb.curated === false`, render a short "No curated profile for this water body — national rules apply" notice in place of the curated lake stats.

The 12 existing call sites of `getStatus` / `getSpeciesStatus` keep their signatures; `getEffectiveSpeciesRule(s.id, wb.id, date)` is what powers the rules card.

## Components

### `<TodaysVerdictBanner>` — `mobile/src/components/TodaysVerdictBanner.tsx`

Props: `{ waterBodyId: string | null; date: Date }`. Reads `getDailyVerdict(...)`. Three states:
- `blanketReason !== null` → red, "Visos rūšys uždarytos: {reason.lt|en}".
- `closed.length > 0` → amber, "Šiandien uždaryta: {names}" (truncate to N, "+k more").
- otherwise → green, "Šiandien atvira visoms rūšims".

Colours from `theme.success / warning / danger / *Soft`. Translations follow the same `lang` pattern used elsewhere.

### `<NationalRulesCard>` — `mobile/src/components/NationalRulesCard.tsx`

Props: `{ date: Date; waterBodyId?: string; lang: 'lt' | 'en' }`. SVG via `react-native-svg` 15.12.1.

**Visual layout governed by `map_ex.png` and `map_ex2.png` — implementer must view both before settling component layout, spacing, hatch density, and column proportions.** No amateur/limited split — render one unified species table.

Data inputs the component must surface:
- Header banner: weight cap text from `NATIONAL_RULES.defaultDailyWeightCapKg` (5 kg) plus the Curonian carve-out (7 kg). When `waterBodyId` resolves to a body with its own `dailyWeightCapKg`, show the body's value primary and the national one as the contrast.
- Free-fishing days from `NATIONAL_RULES.freeFishingDates`.
- Gear summary from `NATIONAL_RULES.gear`.
- Species rows: one per `NATIONAL_SPECIES_RULES` entry, after applying the body's overrides via `getEffectiveSpeciesRule(s.speciesId, waterBodyId ?? '__national__', date)`. Each row shows: name + Latin, the closure window(s) drawn against a 12-month axis, bag, min size, max size, notes.
- Closure rendering: hatched diagonal rect, x-position `monthIndex + (day-1)/daysInMonth(month)`. Year-wrapping windows split into two rects (Dec → year end; year start → Jan).
- Today indicator: thin vertical line at today's column position; rows where `activeClosure !== null` get a "closed today" tag in the rightmost column.
- Footer: source URL + `atnaujinta` date constant from `national.ts`.

LT month headers: Sausis · Vasaris · Kovas · Balandis · Gegužė · Birželis · Liepa · Rugpjūtis · Rugsėjis · Spalis · Lapkritis · Gruodis. EN swap when `lang === 'en'`. Right-column headers per ref photos.
